# Repo-wiki index

> The content catalog. Every page gets one line: link + one-line summary + the code it cites +
> the date it was last verified. Read this **before grepping** — it is the map that points at code.
> Schema and workflows: [WIKI.md](WIKI.md).

_Seeded by `/agentic-harness:harness-init`. Nothing is mapped yet — the first `/agentic-harness:wiki-ingest`
after you build something fills this in._

## Features
_one page per vertical: what it is and how it is wired._

## Decisions
_ADRs: why a choice was made and what was rejected._
